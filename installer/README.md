# SIAP-DESA Windows Installer

This directory defines the packaging contract for the Windows distribution.

## Full installer

Target artifact:

`SIAP-DESA-Setup-1.0.0.exe`

Recommended packaging stack:

- Inno Setup for installation orchestration
- .NET WebView2 desktop shell
- bundled PHP runtime
- bundled local MySQL runtime
- Laravel application
- PowerShell bootstrap scripts

## Installation target

Application:

`C:\Program Files\SIAP-DESA\`

Data:

`C:\ProgramData\SIAP-DESA\`

The installer must create the data directory before starting any service.

## First-run sequence

1. Install runtime.
2. Initialize local MySQL data directory.
3. Create local database.
4. Run Laravel migrations.
5. Generate/persist device UUID.
6. Create first administrator account.
7. Register village/device metadata.
8. Start services.
9. Launch SIAP-DESA.exe.

## Important

The repository contains packaging source and build configuration. The final signed EXE is a release artifact generated by the Windows CI/build environment; it is not committed to Git.
